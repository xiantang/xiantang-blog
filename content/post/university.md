# 回忆我的大学

写这篇回忆录的原因是因为在推特上有一个快要毕业的小伙子在抱怨大学，说大学没有意义，我觉得这个说法特别的片面。所以我想写一篇关于大学的回忆录，来表达我对大学的看法。

这篇文章主要是回忆性质，并不是鼓吹自己有多牛逼的经历，或者说我有多么的成功。只是想把我在大学期间的一些经历和感悟分享给大家。

时间线可能会有些乱，因为我也不是一个喜欢写日记的人，所以很多事情都是凭借记忆来回忆的。

## 高中结束

* 阐述成绩不好
* 学校不好(三本)
* 选专业 


## 迷茫的大一
* 壮志勃勃，但是迷茫
* C 语言
* 尝试单片机，放弃
* 专业分流， 知乎 选择去往计算机班

## 大二找到喜欢的东西
* Python / 我操培训班的课讲的这么清楚？？？？！！！！！！！！！！！
* 送外卖，当理货员 
* 接外包 -> 感觉自己可以
* 与异地恋女友分手
* 同学去日本游学，我因为家庭
* 杭州实习, 机缘巧合认识了管实验室的老师，从此有单独的实验室不需要在寝室窝囊废。
* 有趣的时刻： 晚上聚餐吃完饭喝得烂醉还要去实验室学一会写代码，也在那个时候学了一点机器学习的东西（吴恩达）虽然知道会要写代码，但是还是有一些迷茫。
* 每天没日没夜的在实验室学习，看了很多相关的技能书籍: Algorithms 4th edition, 算法图解，代码之外的软知识。 爬虫相关的书籍 好多本, django 写网站。第一个 python 的后端网站。

## 大三
* 从 python 转换到其他后端语言， Golang
* 转变方向，转向后端方向
* 准备实习，java 好多八股文，yue， 她妈的你做个实习生也他妈的要懂 JVM 脑残？？？？
* 参与第二段实习，爱奇艺 做网关 L4，表现不好，自我怀疑
* 提前准备秋招，认识了很多朋友，这些朋友包括现在都有联系
* 秋招拿了小厂的 offer，但是里面有很多技术强人，并且互相学习， scala
* 小厂实习的时候同时下班学习 scala 更加进阶的技巧， functional programming. functional programming principle in scala
* 当时很憋屈，因为感觉自己落后了很多，所以心里一直憋着一口气
* 参加了一个大数据技能比赛，拿了个二等奖，主要是操作，挺傻逼的。
## 大四

* 准备春招, 春招因为实习经历比较叼，所以拿了很多 offers 包括字节，阅文集团，虾皮新加坡，等一些小厂。 基本上是面一家就过一家。所以好的实习经历非常重要。
* 小厂因为新冠的原因，导致公司裁员，很多校招生不能转正，但是我因为表现好给我转正机会了，果断选择离开。
* 大四后面的时间和室友相聚的机会就越来越少了，有和我一样出去实习在杭州实习的同学，也有大三大四一直在学校宿舍打游戏的同学。不过在我眼里大学真的能选择，能选择你想要做的事情。而不是快毕业的时候才埋冤大学
* 在去字节做正式牛马之前的两个月，什么都没搞，在家躺了两个月，而且那个时候新冠疫情也很严重，一直怀疑自己得了新冠命不久矣，其实是躺太舒服了，哈哈哈。
